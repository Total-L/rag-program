# L19 — 清洗/归一化/近重复 报告

## 关键观察
- **归一化是增量索引能生效的前提**：全角/零宽/CRLF 不归一，每次都算不同 chunk_id → 永远在重嵌
- **样板检测两路**：正则（页眉/页脚）+ 跨文档频率统计（公司特定页脚）
- **MinHash + LSH**：两两比签名是 O(N²)，LSH banding 砍到近似 O(N)
- **★ 阈值必须按文本长度校准**：
  - 长文档改一处 ≈0.97 → 0.92 阈值能抓
  - 短句改 2 字只有 ≈0.66 → 0.92 阈值会漏，必须降到 ~0.6
